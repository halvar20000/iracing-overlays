# Streckennotizen für die KI-Moderation

Hier liegt pro Strecke eine Notizdatei (`.md` oder `.txt`). Wenn die
Moderation die Strecke vorstellt, nimmt Claude **diese Notizen** als Quelle,
also Rundenrekorde, Geschichte und Schlüsselkurven. Ohne Notizen sagt die
Moderation nur allgemein Bekanntes und nennt keine konkreten Zahlen. So
werden keine Rekorde erfunden.

**Dateiname:** Er muss ein Wort aus dem iRacing-Streckennamen enthalten,
z. B. `spa-francorchamps-stream-notes-de.md` für „Circuit de
Spa-Francorchamps“ oder `algarve-stream-notes-de.md` für Portimão / Algarve.
Die Datei mit den meisten passenden Wörtern gewinnt.

Die Notizdateien aus dem Streckennotizen-Skill
(`<strecke>-stream-notes-de.md`) passen direkt, du kopierst sie einfach
hierher. Welche Datei benutzt wurde, steht auf der Seite
`http://localhost:5000/show` unter „Fakten für das Skript“ → `streckennotizen`.
